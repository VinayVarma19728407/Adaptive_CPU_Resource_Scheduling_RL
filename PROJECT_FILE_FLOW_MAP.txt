2. EXECUTIVE OVERVIEW
================================================================================
The project does NOT have a single master runner that chains all stages
automatically. It consists of these DISTINCT manually-run workflows:

  A. Data cleaning        (4 standalone scripts, run once per dataset)
  B. Data preprocessing   (5 standalone scripts, run once per dataset)
  C. Workload analysis / regime / manifest (analysis branch, wired to B outputs)
  D. Synthetic scenario generation  [simulator/scenario_loader.py]
  E. Deterministic baseline simulation  [simulator/environment.py]  <-- CURRENT PRIMARY
  F. RL/PPO environment + MaskablePPO training  [experiments/train_*.py]
  G. PPO evaluation + baseline comparison  [experiments/evaluate_*.py]
  H. Trace-replay scenario builder  [simulator/trace_replay_scenario.py]
  I. Validation / test suite  [tests/, validation/]
  J. Legacy/stub code  [Old/]  -- Git-ignored, stubs only

The "current primary simulation" is the deterministic FCFS event-driven engine in
simulator/environment.py (and its RL wrapper simulator/rl_environment.py), which
is actively trained and evaluated via experiments/train_*.py / evaluate_*.py.

The scenario_loader.py synthetic scenario path is an older, simpler precursor
that generated the three light/moderate/heavy CSVs that also exist on disk.
